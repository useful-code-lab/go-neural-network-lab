# Go Neural Network Lab

Учебная нейронная сеть на Go, созданная **с нуля без сторонних ML-библиотек**.

Проект помогает на практике разобраться, **как устроена нейронная сеть внутри**: как данные проходят через слои, как вычисляются активации, как распространяется ошибка назад и как сеть изменяет веса во время обучения.

Вместо использования готового фреймворка здесь можно увидеть основные механизмы обучения непосредственно в исходном коде.

---

## 🎯 Что вы получите от проекта

Этот репозиторий полезен, если вы хотите не просто использовать нейросети, а **понять, что происходит внутри них**.

С помощью проекта можно:

* разобраться, из чего состоит нейронная сеть;
* понять, как работают веса и смещения (`bias`);
* увидеть вычисление взвешенной суммы и активации;
* разобраться с прямым проходом (`forward pass`);
* понять принцип обратного распространения ошибки (`backpropagation`);
* увидеть, как градиентный спуск изменяет параметры сети;
* наблюдать процесс обучения по эпохам;
* анализировать изменения весов и смещений;
* изучать работу нескольких задач в одной нейросети;
* экспериментировать с архитектурой сети и алгоритмами обучения;
* использовать исходный код как основу для собственных экспериментов с ML на Go.

Главная идея проекта — **сделать внутреннюю механику нейронной сети наблюдаемой и понятной**.

## 🧠 Что умеет сеть

В демонстрационном примере одна многослойная сеть обучается сразу решать три логические задачи:

| Выход сети | Задача |
| ---------- | ------ |
| Output 0   | XOR    |
| Output 1   | AND    |
| Output 2   | OR     |

Архитектура демонстрационной сети:

```text
2 входа
   ↓
6 нейронов скрытого слоя
   ↓
3 выхода
   ├── XOR
   ├── AND
   └── OR
```

Это позволяет на небольшом и понятном примере увидеть, как **одна сеть может одновременно обучаться нескольким задачам**.

---

## 🔬 Что происходит внутри

Для каждого нейрона вычисляется взвешенная сумма входов:

```text
Z = Σ(Wi × Xi) + Bias
```

После этого результат проходит через функцию активации:

```text
A = activation(Z)
```

В процессе обучения сеть сравнивает полученный результат с целевым значением и корректирует параметры.

Упрощённо процесс выглядит так:

```text
Входные данные
      ↓
   Веса + Bias
      ↓
Взвешенная сумма Z
      ↓
Функция активации
      ↓
   Предсказание
      ↓
 Сравнение с целью
      ↓
     Ошибка
      ↓
Backpropagation
      ↓
Обновление весов
      ↓
Следующая эпоха
```

Именно этот цикл постепенно позволяет сети находить подходящие параметры.

## 📊 Наглядное обучение

Проект сохраняет подробную информацию о процессе обучения в `full_log.txt`.

Например:

```text
Epoch 19999 avg loss: 0.000100
max weight change: 0.000057
max bias change: 0.000057
```

Это позволяет не воспринимать обучение как «чёрный ящик», а наблюдать, что происходит с моделью.

### Что можно увидеть в отчётах

**`avg loss`**

Показывает среднюю ошибку сети относительно целевых значений.

**`max weight change`**

Показывает максимальное изменение веса за эпоху.

**`max bias change`**

Показывает максимальное изменение смещения.

Когда изменения параметров становятся небольшими, можно увидеть, что обучение постепенно стабилизируется.

## 🔎 Можно заглянуть внутрь каждого слоя

Проект выводит подробную информацию о работе нейронов:

```text
Neuron 0:
Weights=[4.1025 4.0615]
Bias=-5.7847
Z=-5.7847
A=0.0031
```

Благодаря этому можно проследить путь данных:

```text
Input
  ↓
Weights
  ↓
Z
  ↓
Activation A
  ↓
Output
```

То есть можно не только увидеть итоговое предсказание, но и **разобрать, каким образом сеть его получила**.

## 💻 Пример

Создание сети:

```go
net := nn.NewNetwork([]int{2, 6, 3})
```

Здесь:

* `2` — количество входов;
* `6` — количество нейронов скрытого слоя;
* `3` — количество выходов.

Обучение:

```go
net.TrainBatch(
    samples,
    targets,
    20000,
    0.5,
    f,
)
```

После обучения можно выполнить прямой проход:

```go
out, _, _ := net.ForwardFull(s)
```

и получить предсказание сети.

## ➕ Добавление новой задачи

Новые данные можно добавить в обучающий набор:

```go
allSamples = append(
    allSamples,
    newDataset.Samples...,
)

allTargets = append(
    allTargets,
    newDataset.Targets...,
)
```

Это позволяет экспериментировать с новыми задачами, не меняя базовую концепцию сети.

## 🛠 Добавление собственного алгоритма обучения

Архитектуру можно расширять собственными алгоритмами обучения.

type Trainer interface {

        net *Network,

        targets [][]float64,

    )
}

## 📌 Почему здесь нет ML-фреймворка

Проект специально реализует основные механизмы нейронной сети самостоятельно.

Это позволяет сосредоточиться на фундаментальных принципах:

```text
нейрон
  ↓
веса
  ↓
взвешенная сумма
  ↓
активация
  ↓
предсказание
  ↓
ошибка
  ↓
градиент
  ↓
обновление параметров
```

Поэтому репозиторий прежде всего предназначен для **изучения и экспериментов**, а не для замены полноценных production ML-фреймворков.
